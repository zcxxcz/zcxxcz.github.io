一、推荐推进顺序 为什么是这个顺序

纵向四级台阶是「难度」，横向五模块是「题型」。正确走法是：先把第 1 级的基础模块走完，再让后面四个模块交替推进，避免一个模块卡死。

第 1 步
吃透基础模块
语法、数组、排序、栈队列、前缀和差分、二分、递归与 BFS。后面所有模块都建立在这里。
基础模块 J组 19 项 + S组 4 项
第 2 步
图论 + 树论 打底
邻接表、并查集、最短路、LCA、树状数组、线段树。这两个模块互相喂养，交替推进效率最高。
合计 S组 39 项
第 3 步
DP + 数学 跟上
线性 DP、背包、树形 DP，配合同余、逆元、快速幂。DP 优化和数论定理天然绑定。
合计 S组 26 项
第 4 步
冲 NOIP 提高级
网络流、Tarjan 全家桶、扫描线、数位 DP、矩阵加速。这一级开始拼综合建模能力。
NOIP 全模块 27 项
第 5 步
省选 / NOI 竞赛级
持久化、树套树、LCT、莫队、FFT、莫比乌斯反演。按模块挑，不建议全铺。
省选/NOI 全模块 88 项

二、跨模块的依赖链 最容易踩坑的地方

数组 / 循环 → 前缀和 / 差分 → 树上差分（图论模块）
排序 / 二分 → 二分答案 → 线段树二分（树论）→ CDQ 分治（树论）
递归 / DFS / BFS → 最短路 → 分层图最短路、次短路、K 短路（图论）
并查集 → 可持久化并查集 / 可撤销并查集（树论）；Kruskal → 最小生成树 → 次小生成树 → Kruskal 重构树
二叉树 / 遍历 → 树状数组 → 线段树（树论）→ 树链剖分 → 动态树 LCT
树形 DP 与树论高度重叠：树的直径、树的重心、树形背包建议与树论合并学，不要分成两条线
快速幂 → 矩阵快速幂（数学）→ 矩阵加速 DP（DP 模块）
同余 / 逆元 → 费马小定理 → 扩展欧几里得 → 中国剩余定理 → BSGS / 莫比乌斯反演（数学）
线段树 是全局枢纽：既是树论主干，又是 DP 优化（线段树优化 DP）、图论（线段树优化建图）的脚手架
