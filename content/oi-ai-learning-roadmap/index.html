迷宫里的搜索顺序

BFS搜索路径恢复A*
打开项目方案 0 / 4 项自查

怎样推进

  1. 实现无权四邻接网格的 BFS，恢复最短路径；再比较 DFS 和只朝目标走的贪心策略。
  2. 掌握优先队列后加入 A*，以曼哈顿距离作启发式。

PROJECT 0312—16 小时

推断看不见的天气

动态规划HMM概率路径恢复
打开项目方案 0 / 4 项自查

怎样推进

  1. 构造两状态 HMM，给定初始、转移和观测概率。
  2. 在很短的序列上穷举全部隐藏路径，得到参照。

PROJECT 0412—16 小时

打开项目方案 0 / 4 项自查

怎样推进

PROJECT 0512—18 小时

规则未知的网格世界

规则已知时计算价值，规则未知时通过交互估计。让两种方法回答同一个决策问题。

动态规划概率强化学习Q-learning
打开项目方案 0 / 4 项自查

怎样推进

  1. 先在确定性小网格中用 BFS 求最短路。
  2. 加入随机滑动，明确转移概率，用价值迭代得到已知模型下的参照。
  3. 隐藏转移概率，仅允许交互，训练表格型 Q-learning。
  4. 统一奖励、折扣、终止条件，比较不同训练量与随机种子的收益。

验收与自查

只以位置为状态的表格 Q-learning，不会默认迁移到任意新地图。随机环境中也不能只拿路径长度作全部评价。

打开项目方案 0 / 4 项自查

怎样推进

DIRECTION A

博弈与强化学习

搜索 · 状态压缩 · 估值 · 随机化

UCT 与蒙特卡洛规划 ↗DQN ↗AlphaZero ↗加餐：PPO ↗

网络估值，能否帮助搜索？

升级已经验证规则的棋类程序，比较“只有搜索”“只有小网络”“网络＋搜索”三种版本。先在井字棋中校准实现，再考虑更大的棋盘变体。

要回答的问题
  • 相同搜索次数下，网络先验与估值是否改善结果？
  • 算上网络推理成本，相同总时间下是否仍有收益？
  • 去掉组件后结果如何变化？哪些局面会系统性误判？

研究网络、搜索、自我对弈与训练数据的循环。按实际范围标为小型机制实验；不要把有限搜索对手称为完美对手。

DIRECTION B

图与组合优化

状压 DP · 图论 · 近似解 · 精确检查

Pointer Networks ↗神经组合优化 ↗加餐：GCN ↗加餐：神经算法推理 ↗

学习出来的路线，离最优有多远？

从不超过 12 个城市的二维旅行商问题开始。用状压 DP 求精确最优解，设置最近邻等基线；再尝试 Pointer Network，有余力再进入强化学习训练。

必须保留的证据
  • 路线是否合法；非法输出单独统计，不悄悄丢弃。
  • 与最优解的长度差、单次求解耗时和总训练成本。
  • 未见坐标、规模与分布上的变化，多个种子的结果。

等价最优路线允许不同。图学习学生可用精确图算法生成监督数据，研究可达性预测；这类拓展要与原论文复现区分。

DIRECTION C

语言模型与计算效率

矩阵 · 低秩 · 分块 · 内存访问

LoRA 低秩微调 ↗FlashAttention ↗加餐：Scaling Laws ↗加餐：Chinchilla ↗

相同的计算，为什么成本不同？

实现普通注意力，再研究分块与在线 softmax。比较输出误差、内存和时间；或固定基础模型与数据，比较 LoRA 不同秩与全量微调。

怎样进行公平比较
  • 事先约定数值误差容限，核对参考实现。
  • 解释哪些中间结果保存、哪些重算，统一设备与精度。
  • 同时报告效果与成本，不把少量曲线外推为普遍规律。

CPU 教学实现用于验证机制；GPU 性能结论另用兼容设备测量。LoRA 仍保留基础权重，节省的是可训练更新与相关资源。

把“实现核心机制”“复核部分实验”和“对齐原论文指标”分别写清。只选择公开细节齐全、资源可承担的子实验。

06 / MAKE IT REPRODUCIBLE

一个模块，走完一次证据闭环。

普通模块约 6—8 周，高级项目可持续一学期。节奏按已有能力与竞赛安排调整。

WEEK 01—02

先写可靠基线

复习信奥知识，列边界样例，说明复杂度与正确性条件。

WEEK 03

读懂一个方法

读讲义和论文节选，手算小例子，交一页方法说明。

WEEK 04—05

实现并检查

写核心代码，对拍、检查梯度或验证模型输入输出。

WEEK 06—08

实验与答辩

控制变量，记录失败，换条件测试，解释结论与适用范围。

每个项目，留下六样东西。

把讨论变成别人可以检查、自己可以重跑的材料。

问题定义可靠基线核心代码数据与配置原始结果结论与局限

验收看四种能力。

算法理解：状态、转移、复杂度与条件。
实现能力：独立调试，能接受换规则测试。
实验判断：比较公平，区分训练与测试。
表达能力：说清做到了什么，还有什么没做到。
