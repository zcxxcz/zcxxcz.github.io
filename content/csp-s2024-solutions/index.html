一、T1 决斗（P11231）

1.1 题意

有 n 只怪兽，第 i 只攻击力 = 防御力 = r_i。每回合选两只不同的存活怪兽 i、j，让 i 攻击 j：

  • 若 r_i ≤ r_j，无事发生；
  • 否则 r_j 被打破，怪兽 j 退场。

每只怪兽整场至多只能发起一次攻击。当所有存活怪兽都发起过攻击时游戏结束。求游戏结束时存活怪兽数量的最小值。

样例 1：5 / 1 2 3 1 2 → 2；样例 2：10 / 136 136 136 2417 136 136 2417 136 136 136 → 8。

1.2 数据范围与子任务表

对于所有测试数据：1 ≤ n ≤ 10⁵，1 ≤ r_i ≤ 10⁵。

测试点 n r_i 特殊性质 分值 累计
1~4 ≤ 10 ≤ 10⁵ 无特殊性质 20 20
5~10 ≤ 10⁵ ≤ 2 无特殊性质 30 50
11~15 ≤ 30 ≤ 10⁵ 特殊性质 A 25 75
16~20 ≤ 10⁵ ≤ 10⁵ 无特殊性质 25 100

特殊性质 A：保证每个 r_i 在可能的值域中独立均匀随机生成。

另外样例 3 满足 ∀i, r_i ≤ 2（就是第 5~10 个测试点的样子）。

1.3 核心结论（全题地基）

把"怪兽 i 消灭怪兽 j"看成二分图的一条边：左边是「攻击者」，右边是「受害者」，边 L_i → R_j 存在当且仅当 r_i > r_j。

由于"一只怪兽可以既攻击一次、又被消灭一次"，所以左、右两边是同一批点的两份拷贝，消灭数 = 这张二分图的最大匹配，答案 = n − 最大匹配。

结论：最大匹配 = n − (出现次数最多的那个数值的出现次数)。也就是
答案 = max_v cnt[v]（众数的个数）。

证明（两行）：把 r 排好序，按"同一数值内部无法互相消灭、大值可以消灭小值"做链分解，可以贪心地把整个序列拆成 cnt[v] 条严格上升的链（链长之和 = n，链数 = 众数个数 k）。每条链内部前一个能消灭后一个，所以每条链贡献 len−1 次消灭，总消灭数 n−k。另一方面，每个数值 v 的 cnt[v] 只怪兽互相无法消灭，其中至少 1 只必定存活（更强的怪兽可以消灭更弱的，但同值互相打不动），所有出现次数最多的那个值就至少留下 k 只 —— 两边夹住，答案是 k。

用手算验证样例 1：1 2 3 1 2 中 1 和 2 各出现 2 次，众数个数 2 → 答案 2 ✓。样例 2 中 136 出现 8 次 → 答案 8 ✓。

1.4 一档一档来

档 1（20 分，测试点 1~4，n ≤ 10）：暴搜攻击顺序

直接模拟规则，搜索所有"下一步攻击"的选择，取存活数最小。用 (存活集合, 已攻击集合) 做状态记忆化，状态数 ≤ 3ⁿ ≈ 6×10⁴，n ≤ 10 秒过。

为什么这一档只需要这些：n ≤ 10 时指数级搜索完全够用，不需要任何性质，是本题的正确性锚点（后面两份代码都用它对拍）。

C++
// 20分：n<=10 暴力搜索（记忆化）
#include <bits/stdc++.h>
using namespace std;
int n, r[12];
unordered_map<int, int> memo;              // key = aliveMask*1024 + atkMask
int dfs(int alive, int atk) {
    if ((alive & ~atk) == 0) return __builtin_popcount(alive);   // 存活者都已攻击
    int key = alive * 1024 + atk;
    auto it = memo.find(key);
    if (it != memo.end()) return it->second;
    int best = __builtin_popcount(alive);   // 无人可攻击（如 n=1）时游戏直接结束
    for (int i = 0; i < n; i++) {
        if (!(alive >> i & 1) || (atk >> i & 1)) continue;       // i 存活且未攻击
        for (int j = 0; j < n; j++) {
            if (i == j || !(alive >> j & 1)) continue;           // 目标 j 存活
            int na = alive, nat = atk | (1 << i);
            if (r[i] > r[j]) na &= ~(1 << j);                    // 打破防御 -> j 退场
            best = min(best, dfs(na, nat));
        }
    }
    return memo[key] = best;
}
int main() {
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &r[i]);
    printf("%d\n", dfs((1 << n) - 1, 0));
    return 0;
}

档 2（补到 50 分，测试点 5~10，r_i ≤ 2）：直接分类计数

只有 1 和 2 两种数值：

  • 2 能消灭 1；2 之间、1 之间互相打不动。
  • 最优策略：每个 2 去消灭一个 1；消灭完 1 之后的 2、以及没被消灭的 1 都只能留下。
  • 所以存活数 = max(个数1, 个数2)。

为什么这一档只需要这些：值域只有 2 个点，最优结构显然（大者吃小者），不需要排序或匹配。

C++
// 50分档：特殊性质 r_i<=2
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; scanf("%d", &n);
    int c1 = 0, c2 = 0;
    for (int i = 0, x; i < n; i++) { scanf("%d", &x); (x == 1 ? c1 : c2)++; }
    printf("%d\n", max(c1, c2));
    return 0;
}

注意：这份代码只对 r_i ≤ 2 成立（它是按"大于 1 的都算 2"写的）；换成别的数据会错，这是子任务专用代码。

档 3（补到 75 分，测试点 11~15，n ≤ 30，特殊性质 A）：排序 + 双指针求最大匹配

把 r 升序排序。受害者 j 从小到大枚举，给每个受害者配"能消灭它的、编号最小的攻击者"：攻击者指针 i 一路向后走，遇到 r[i] > r[j] 就配一对（i++、j++），否则 i++ 继续找更大的攻击者。这是"阈值型二分图"最大匹配的标准贪心，O(n log n)。

为什么这一档只需要这些：特殊性质 A 保证 r_i 在值域内均匀随机，n ≤ 30 时几乎必定两两不等，此时最大匹配 = n−1（一条长链），任何正确算法都能过；但随机数据里也可能出现少量重复值，用贪心才稳。

C++
// 75分档：排序 + 双指针最大匹配（O(n log n)，实际已达满分）
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; scanf("%d", &n);
    vector<int> r(n);
    for (int i = 0; i < n; i++) scanf("%d", &r[i]);
    sort(r.begin(), r.end());
    int i = 0, killed = 0;                   // i: 攻击者指针
    for (int j = 0; j < n; j++) {            // j: 受害者指针，从小到大
        while (i < n && r[i] <= r[j]) i++;   // 找"能消灭 r[j] 的最小攻击者"
        if (i < n) { killed++; i++; }
    }
    printf("%d\n", n - killed);
    return 0;
}

档 4（100 分）：众数

上面 1.3 的结论直接扫描统计。

为什么这一档只需要这些：拿到"答案 = 众数"这个结论后，代码只剩 5 行；这也是本题唯一需要"想"的地方。

1.5 完整正解代码

C++
// T1 决斗 P11231 -- 100分正解：答案 = 众数的出现次数
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; scanf("%d", &n);
    map<int, int> cnt; int ans = 0;
    for (int i = 0, x; i < n; i++) { scanf("%d", &x); ans = max(ans, ++cnt[x]); }
    printf("%d\n", ans);
    return 0;
}

（值域 ≤ 10⁵，把 map 换成 int cnt[100005] 会更快；两种写法都对。）

1.6 易错点

  1. n = 1 的边界：只有一只怪兽、无人可攻击，游戏立即结束，答案 1。暴力搜索里如果只在"有合法招式"时才更新答案，会在 n=1 时返回 INF —— 必须把"停手"也当成一个合法终态（本文暴力里 best 初始化为当前存活数就是为了这个）。
  2. 别把"攻击者"限制在"没人能消灭它"的怪兽里：怪兽可以既被消灭又发起攻击（在被消灭之前攻击即可），排序双指针把攻击者、受害者当成两份独立拷贝才正确。
  3. 双指针写法常见坑：受害者指针必须从最小的开始（"最小者也能被更大的消灭"）；只让攻击者从小的开始、受害者从第二个开始，会少算一次。
  4. 特判子任务代码不要拿去交正解：r_i ≤ 2 那份代码在 r_i > 2 时会 WA。

  • n = 10⁵ 随机数据：0.02 s / 8.9 MB。

二、T2 超速检测（P11232）

2.1 题意

一条长 L 的南北主干道，第 i 辆车在距南端 d_i 处驶入，初速度 v_i，加速度 a_i（a_i 可正可负可零），做匀加速运动向北行驶。车到达最北端（L）或速度降为 0（只可能在 a_i < 0 时发生）就驶离主干道。

道路上有 m 个测速仪，第 j 个位于 p_j。车经过某个开启的测速仪时，若瞬时速度严格超过限速 V，就被判定超速。（在驶入点 d_i、驶出点 L 处的测速仪也会测速。）

两个问题：

  1. 若所有测速仪都开启，有多少辆车会被判定超速？
  2. 在不漏掉任何"本来会被判超速"的车的前提下，最多能关闭多少个测速仪？（输出关闭数）

多组测试数据：第一行 T，每组先 n m L V，再 n 行 d_i v_i a_i，最后一行 m 个数 p_1<p_2<…<p_m。

样例 1：5 5 15 3 / (0,3,0) (12,4,0) (1,1,4) (5,5,−2) (6,4,−4) / 2 5 8 9 15 → 3 3。

2.2 数据范围与子任务表

对于所有测试数据：1 ≤ T ≤ 20；1 ≤ n,m ≤ 10⁵，1 ≤ L ≤ 10⁶，1 ≤ V ≤ 10³；0 ≤ d_i < L，1 ≤ v_i ≤ 10³，|a_i| ≤ 10³；0 ≤ p_1 < p_2 < … < p_m ≤ L。

测试点 n, m ≤ 特殊性质 分值
1 10 无 10
2 20 无 10
3 3000 A 10
4 10⁵ A 10
5 3000 B 10
6 10⁵ B 10
7 3000 C 10
8 10⁵ C 10
9 3000 无 10
10 10⁵ 无 10
  • 特殊性质 A：保证 a_i = 0。
  • 特殊性质 B：保证 a_i > 0。
  • 特殊性质 C：保证 a_i < 0，且所有车都不在最北端驶离主干道。

样例 2 满足 n,m ≤ 10；样例 3/4/5 分别满足 A/B/C，且其中前十组数据满足 n,m ≤ 3000。

2.3 两个核心观察（全题地基）

观察 1：用整数判超速，彻底避开浮点误差

车在位置 x（x ≥ d_i）处的瞬时速度满足

v(x)² = vi² + 2ai(x − di)

所以"在 x 处超速" ⟺ v_i² + 2a_i(x−d_i) > V²，两边全是整数，直接比大小即可，不需要 sqrt、不需要 eps。

对测速仪 j：车必须真的经过它（p_j ≥ d_i），于是

车 i 被测速仪 j 判超速  ⟺  pj ≥ di  且  vi² + 2ai(pj − di) > V²

一辆车是否超速（问题 1）就是"是否存在这样的 j"。

观察 2：每辆超速车对应的测速仪是一段连续下标，问题 2 = 最少点覆盖区间

固定一辆车 i，把 p 数组按位置排序后，满足上式的 j 一定构成一个连续的下标区间 [lo_i, hi_i]：

  • 若 a_i ≥ 0：v(·)² 随位置单调不减 ⇒ 区间是后缀：[第一个满足条件的 j, m]；
  • 若 a_i < 0：v(·)² 随位置单调不增 ⇒ 区间是前缀：[lower_bound(d_i), 最后一个满足条件的 j]。

（a_i ≥ 0 时"第一个满足条件的 j"用二分找；a_i < 0 时"最后一个满足条件的 j"用二分找。）

这样问题 2 就变成经典问题：

有若干条线段 [lo_i, hi_i]，要求选最少的点，使每条线段都至少被一个选中点覆盖。

标准贪心：按右端点升序扫，维护上一个选中的点 last；若 last < lo_i，就在 hi_i 处选一个点。（可选点数最少 ⇒ 关闭数 = m − 最少点数。）

用样例 1 验证：测速仪 p = (2,5,8,9,15)（下标 1~5）。

  • 车 2（d=12, v=4, a=0）：区间 [5,5]；
  • 车 3（d=1, v=1, a=4）：只有 p_1=2 处不超速（1+8·1=9 不 > 9），区间 [2,5]；
  • 车 4（d=5, v=5, a=−2）：p=5(idx2) 时 25>9 ✓、p=8(idx3) 时 13>9 ✓、p=9(idx4) 时 9≯9 ✗ ⇒ 区间 [2,3]。

问题 1 = 3 ✓。最少点：按右端点排序 [2,3],[5,5],[2,5]，先选 3（覆盖前两条），再选 5（覆盖 [5,5]）⇒ 2 个点，关闭 5−2 = 3 ✓。

档 1（20 分，测试点 1~2，n,m ≤ 20）：暴力

  • 问题 1：逐车逐测速仪，用整数比较判断。
  • 问题 2：把每辆超速车"能拍到它的测速仪"压成一个位掩码，枚举所有保留集合（m ≤ 20 ⇒ 2²⁰ 种），对每种检查是否覆盖了所有超速车，取 popcount 最小者。

为什么这一档只需要这些：m ≤ 20 时 2^m 枚举 + O(n) 校验完全够；这是本题的正确性锚点。

C++
// 20分：n,m<=20 暴力（问题2 枚举保留子集）
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
ll d[25], v[25], a[25], p[25];
int main() {
    int T; scanf("%d", &T);
    while (T--) {
        int n, m; ll L, V;
        scanf("%d %d %lld %lld", &n, &m, &L, &V);
        for (int i = 0; i < n; i++) scanf("%lld %lld %lld", &d[i], &v[i], &a[i]);
        for (int j = 0; j < m; j++) scanf("%lld", &p[j]);
        int ans1 = 0, mask[25];
        for (int i = 0; i < n; i++) {
            int mk = 0;
            for (int j = 0; j < m; j++) {
                if (p[j] < d[i]) continue;                        // 车从 d 向北行驶
                ll vsq = v[i] * v[i] + 2 * a[i] * (p[j] - d[i]);  // 该处速度平方（整数）
                if (vsq > V * V) mk |= 1 << j;
            }
            mask[i] = mk;
            if (mk) ans1++;
        }
        int best = m + 1;
        for (int s = 0; s < (1 << m); s++) {
            int c = __builtin_popcount(s);
            if (c >= best) continue;
            bool ok = true;
            for (int i = 0; i < n && ok; i++) if (mask[i] && !(s & mask[i])) ok = false;
            if (ok) best = c;
        }
        if (best > m) best = 0;
        printf("%d %d\n", ans1, m - best);
    }
    return 0;
}

档 2（+20 分，测试点 3~4，特殊性质 A：a_i = 0）

全部匀速：车从 d_i 一直开到 L（v_i > 0 不会中途停下）。

  • 若 v_i > V，车全程超速，一定被最北的那个测速仪 p_m 拍到（只要 p_m ≥ d_i）；
  • 问题 2：所有超速车对应的区间都是后缀 [·, m]，公共交于点 m ⇒ 只留 1 个测速仪就够。

于是：

C++
// 特殊性质A (a_i=0)
int ans1 = 0;
for (int i = 0; i < n; i++) if (v[i] > V && d[i] <= p[m-1]) ans1++;
printf("%d %d\n", ans1, ans1 > 0 ? m - 1 : m);

（ans1 > 0 ⇒ 关闭 m−1 个、只留最北那个；否则一个都不用留，关闭全部 m 个。）

为什么这一档只需要这些：匀速 ⇒ 速度不随位置变化，"是否超速"与位置无关，只剩"车前方有没有测速仪"这一个条件。

档 3（+20 分，测试点 5~6，特殊性质 B：a_i > 0）

全程加速：v(x)² 严格递增 ⇒ 越是靠北的测速仪越容易拍到 ⇒ 判断最北测速仪即可，区间同样是后缀。

C++
// 特殊性质B (a_i>0)
int ans1 = 0;
for (int i = 0; i < n; i++)
    if (d[i] <= p[m-1] && v[i]*v[i] + 2*a[i]*(p[m-1]-d[i]) > V*V) ans1++;
printf("%d %d\n", ans1, ans1 > 0 ? m - 1 : m);

为什么这一档只需要这些：单调递增 ⇒ 后缀区间 ⇒ 公共交于 m，结论与 A 完全相同，只是判定式子换成"在最北测速仪处的速度平方"。

档 4（+20 分，测试点 7~8，特殊性质 C：a_i < 0 且都不在最北端驶离）

全程减速：v(x)² 单调递减 ⇒ 每辆车的超速区间是前缀 [d_i, x₀)。此时不同车的区间左端不同，公共交不再是同一个点，必须用贪心。

做法与 2.3 完全一致（只保留 a_i < 0 那一支）：

C++
// 特殊性质C (a_i<0, 都不在最北端驶离)
ll Vsq = V * V;
vector<pair<int,int> > seg;                       // (右端点, 左端点)
int ans1 = 0;
for (int i = 0; i < n; i++) {
    int st = lower_bound(p, p + m, d[i]) - p;     // 第一个 >= d_i 的测速仪
    if (st == m) continue;
    ll v2 = v[i] * v[i];
    int l = st, r = m - 1, res = -1;              // 值单调不增 -> 找最后一个 true
    while (l <= r) {
        int mid = (l + r) >> 1;
        if (v2 + 2*a[i]*(p[mid]-d[i]) > Vsq) res = mid, l = mid + 1; else r = mid - 1;
    }
    if (res != -1) { ans1++; seg.push_back(make_pair(res, st)); }
}
sort(seg.begin(), seg.end());                     // 按右端点升序
int cover = 0, last = -1;
for (size_t k = 0; k < seg.size(); k++)
    if (last < seg[k].second) { cover++; last = seg[k].first; }
printf("%d %d\n", ans1, m - cover);

为什么这一档只需要这些：性质 C 让"减速车不会开到北端"这件事成立了，于是区间必然是"从 d_i 开始的连续前缀"，不用再管 L 截断的边界；但贪心不能被省掉，这正是从 A/B 迈向正解的关键一步。

⚠️ 这三份部分分程序【怎么用】—— 单独交是拿不到分的

上面 t2_a.cpp / t2_b.cpp / t2_c.cpp 三份，都是**"假设数据满足某条特殊性质"才能正确的片段程序。正式评测是一题只交一份程序**，判题机不会告诉你这份数据属于哪个子任务。所以：

  • 单独交 t2_a.cpp：只有数据恰好满足 a_i = 0 的测试点（3~4 号，20 分）能过，其余 8 个测试点会被判错，连档 1 的暴力分都拿不到；
  • 同理 t2_b.cpp、t2_c.cpp 各自只能覆盖 20 分。

正确用法有两种：

用法一（推荐，考场就是这个）：把 A/B 合并、C 当另一支 —— 拼出来就是正解。

部分分 合并后等价于
A（a_i = 0）+ B（a_i > 0） a_i ≥ 0 一整支 —— 超标位置是「后缀」
C（a_i < 0 且不驶出北端） 就是 a_i < 0 的通用情形 —— 超标位置是「前缀」

注意 C 里那个"不驶出北端"的条件对代码没有任何影响：a_i < 0 时 v²+2a(p−d) 随 p 严格递减，超标位置天然是一段前缀 [st, res]，只在下标范围 [st, m−1]（即 p ≤ L）里找，L 截断自动生效。所以 t2_c.cpp 原样就能处理"减速但会开出北端"的数据。

⇒ t2_ac.cpp 的 a_i >= 0 那一支 = A+B，else 那一支 = C，再加个区间贪心就是 100 分。 你不需要为 A/B/C 各写一份。

用法二（如果你只会写特殊性质、写不出正解）：写「探测 + 分派」框架。

先读入本题数据，判断它满足哪条特殊性质，满足就调对应快解，都不满足再退回暴力兜底（保证不输出错误答案）。见同目录 t2_merged.cpp，核心骨架：

// 分派

档 5（100 分，测试点 9~10）：整数区间 + 贪心

2.6 易错点

  1. 浮点误差：用 sqrt 或 double 比大小，在 v²+2as 恰好等于 V² 的边界上会判错。必须用整数比较 v_i² + 2a_i(p_j−d_i) > V²。
  2. 严格大于：题目是"速度超过 V"，等于 V 不算。所以二分用的是 > 而不是 ≥，且 a_i<0 时 v(·)² 的零点也要当不超速。
  3. "p_j ≥ d_i" 不能漏：车从 d_i 向北开，只有位置 ≥ d_i 的测速仪才会被经过。漏掉这一条会把车后面的测速仪也算进去。
  4. a_i < 0 的车可能中途停下：停下之后 v² ≤ 0 < V²，自然不超速，所以不用额外判断停车点；但要注意 v²+2a(p−d) 会变成负数，所以变量要用 64 位并允许负值（int 在 p−d 到 10⁶、|a| 到 10³ 时是 2×10⁹，极限会溢出 int，务必用 long long）。
  5. L 截断：性质 C 保证不驶出北端，正解里却要处理 a_i<0 且能开到 L 的情况 —— 因为 p_m ≤ L 且我们只在下标范围 [st, m−1] 内找，天然被截断，无需特判。
  6. 贪心排序关键字：按右端点升序（不是左端点）。同右端点时按左端点升序/降序都不影响结果。
  7. 多组数据记得清空 seg（本文是局部变量，天然没问题；写成全局数组则要手动 clear）。

三、T3 染色（P11233）

3.1 题意

给定长度 n 的正整数数组 A，把每个 A_i 染成红色或蓝色。设 C 为得分数组：

  • 若 A_i 左侧没有与它同色的数，则 C_i = 0；
  • 否则设 j 为 A_i 左侧最靠近的同色数的下标：若 A_i = A_j，则 C_i = A_i，否则 C_i = 0。

求 ΣC_i 的最大值。多组数据：第一行 T，每组给出 n 和数组 A。

样例：[1,2,1] → 1；[1,2,3,4] → 0；[3,5,2,5,1,2,1,4] → 8。

3.3 状态设计与核心引理（全题地基）

第一步：朴素状态

按位置从左到右染色。要注意"得分"只取决于每个颜色最后出现的数值，所以设

dp[x][y] = 已经处理了前 i 个数，红色最后一个数是 x、蓝色最后一个数是 y 时的最大得分。

x = 0 表示"红色还没出现过"（A_i ≥ 1，所以 0 天然代表空）。初始 dp[0][0] = 0。

处理 A_i = a 时：

  • 把 i 染红：新状态 (a, y)，得分增量 [x == a] · a；
  • 把 i 染蓝：新状态 (x, a)，得分增量 [y == a] · a。

答案 = 所有状态的 dp 最大值（红蓝起点对称，不会有遗漏）。

引理 1（红蓝对称）

交换红蓝两种颜色是双射且不改变得分 ⇒ dp[x][y] = dp[y][x]。

引理 2（状态只需一维）

处理完第 i 个数后，第 i 个数不是红就是蓝 ⇒ 状态 (x, y) 中必有一维等于 a_i。

于是整个 dp 只由"十字"上的值决定：记

D_i[v] := dp_i(a_i, v) = dp_i(v, a_i)（引理 1 保证两种写法相同）。

D_i 是一个长度 maxA+1 的一维数组。每步只更新一个下标，其余整体加同一个数：

Di[v] = max( Di−1[v] + add全局加, [ v = ai−1 ] · M单点 chmax )

其中 add = ai（当 ai−1 = ai），否则 add = 0

M = max( maxu ≠ ai Di−1[u] , Di−1[ai] + ai ) = max( G , Di−1[ai] + ai )

其中 G = max_v Di-1[v] 是上一轮的全局最大值。

为什么 M 里的"去掉 a_i 的最大值"可以直接用全局最大值 G：
若全局最大不在 a_i 上，则 maxu≠a_i D[u] = G；若全局最大唯一落在 a_i 上，则 G = D[a_i] ≤ D[a_i] + a_i，直接用 max(G, D[a_i]+a_i) 得到的还是 D[a_i]+a_i，与真值相同。两种情况都对。

最后全局最大值也跟着更新：

Gi = max( Gi−1 + add , M )

答案 = G_n。

第三步：用惰性标记做到 O(n)

D 上只有三种操作：全体加一个数、单点 chmax、查全局 max。用一个 tag 表示"累加的偏移"：真实值 = stored[v] + tag。

  • 全局加 add ⇒ tag += add；
  • 单点 chmax (prev, M) ⇒ stored[prev] = max(stored[prev], M − tag)；
  • 全局 max ⇒ 维护一个变量 G（真实值），G = max(G + add, M)。

prev = ai-1 在上面的推导里就是"上一轮那一个非 ai-1 的维度"所在下标。整个过程每个 i 只做 O(1) 次操作 ⇒ O(n) 时间 / O(maxA) 空间。

档 2（补到 35 分，测试点 5~7，n, A_i ≤ 100）：朴素二维 DP 滚动

把 3.3 第一步的 dp[x][y] 直接实现成 (maxA+1)² 的矩阵滚动。每次 i 遍历所有 (x, y)，往 (a, y) 和 (x, a) 转移。

为什么这一档只需要这些：值域 ≤ 100 时二维矩阵放得下；这一步的作用是把状态定义先写对（很多人一上来就想 O(n)，反而漏掉"红蓝对称"这一步）。

        for (int i = 1; i <= n; i++) { scanf("%d", &a[i]); A = max(A, a[i]); }
        vector<vector<long long> > dp(A + 1, vector<long long>(A + 1, NEG));
        dp[0][0] = 0;
        for (int i = 1; i <= n; i++) {
            int c = a[i];
            vector<vector<long long> > nd(A + 1, vector<long long>(A + 1, NEG));
            for (int x = 0; x <= A; x++) for (int y = 0; y <= A; y++) {
                long long v = dp[x][y];
                if (v == NEG) continue;
                nd[c][y] = max(nd[c][y], v + (x == c ? c : 0));    // 染红: (c, y)
                nd[x][c] = max(nd[x][c], v + (y == c ? c : 0));    // 染蓝: (x, c)
            }
            dp.swap(nd);
        }
        long long ans = 0;
        for (int x = 0; x <= A; x++) for (int y = 0; y <= A; y++) ans = max(ans, dp[x][y]);
        printf("%lld\n", ans);
    }
    return 0;
}

档 3（补到 65 分，测试点 8~10 与 13~15）：压成一维 D[v]

用引理 1、2：每个状态必有一维等于 a_i，且红蓝对称 ⇒ 只维护 D[v] = dp(a_i, v)。转移就是 3.3 的式子，不做惰性标记、老老实实每轮扫一遍 O(A)。

复杂度 O(n·A)：对 n,A ≤ 2000（10⁶）和 n ≤ 2×10⁵, A ≤ 10（2×10⁶）都够用。

为什么这一档只需要这些：值域小的时候 O(n·A) 已经够快，不需要懒标记；而它已经能把 13~15（A_i ≤ 10）那 15 分拿下。

C++
// 65分：O(n*A) 一维 DP（D[v] = 上一位与 v 配对时的最大得分）
#include <bits/stdc++.h>
using namespace std;
const long long NEG = -1e18;
int n; int a[200005];
int main() {
    int T; scanf("%d", &T);
    while (T--) {
        scanf("%d", &n);
        int A = 0;
        for (int i = 1; i <= n; i++) { scanf("%d", &a[i]); A = max(A, a[i]); }
        vector<long long> D(A + 1, NEG), nD(A + 1);
        D[0] = 0;
        int prev = 0;                               // 虚拟的 a_0 = 0
        for (int i = 1; i <= n; i++) {
            int c = a[i];
            long long add = (prev == c) ? c : 0;
            long long G = NEG;
            for (int v = 0; v <= A; v++) G = max(G, D[v]);          // 全局 max
            long long M = max(G, D[c] + c);
            for (int v = 0; v <= A; v++) nD[v] = D[v] + add;        // 全局加
            if (nD[prev] < M) nD[prev] = M;                          // 单点 chmax (index=prev)
            D.swap(nD);
            prev = c;
        }
        long long ans = 0;
        for (int v = 0; v <= A; v++) ans = max(ans, D[v]);
        printf("%lld\n", ans);
    }
    return 0;
}

档 4（100 分，测试点 11~12 与 16~20）：加上惰性标记

观察档 3 的循环：每轮做的是 ① 全体加 add ② 单点 chmax ③ 求全局 max。只有"全体加"看起来必须 O(A)，但它可以用一个 tag 记着不真的加 —— 于是每轮 O(1)，总复杂度 O(n)。

为什么这一档只需要这些：只在 A 很大（10⁶）时 O(n·A) 才会爆炸；把"全局加"变成"记账"就能一次砍掉 A 这个因子。

#include <bits/stdc++.h>
using namespace std;
const long long NEG = -1e18;
static long long D[(int)1e6 + 5];        // 存的是"真实值 - tag"
static int a[(int)1e6 + 5];
int n;
int main() {
    int T; scanf("%d", &T);
    while (T--) {
        scanf("%d", &n);
        int A = 0;
        for (int i = 1; i <= n; i++) { scanf("%d", &a[i]); A = max(A, a[i]); }
        for (int v = 0; v <= A; v++) D[v] = NEG;   // 只需清 0..A
        D[0] = 0;
        long long tag = 0, G = 0;                  // tag: 全局偏移; G: 全局最大值(真实值)
        int prev = 0;                              // 虚拟的 a_0 = 0
        for (int i = 1; i <= n; i++) {
            int c = a[i];
            long long add = (prev == c) ? c : 0;
            long long Dc = D[c] + tag;             // 真实的 D_{i-1}[c]
            long long M = max(G, Dc + c);
            tag += add;                            // ① 全局加
            long long t = M - tag;                 // ② 单点 chmax at index prev
            if (D[prev] < t) D[prev] = t;
            G = max(G + add, M);                   // ③ 新的全局最大值
            prev = c;
        }
        printf("%lld\n", G);
    }
    return 0;
}

3.6 易错点

  1. 答案要开 long long：最坏情况 n·A = 2×10⁵ × 10⁶ = 2×10¹¹，超过 int。（实测 n=2×10⁵、A_i≤10⁶ 时确实输出 10⁸ 量级。）
  2. x（或 y）取 0 表示"该颜色还没出现"：因为 A_i ≥ 1，0 永远不会和真实数值撞车。若把初值设成 −1 等，会不小心触发 [x == a] 的加分逻辑，答案偏大。
  3. prev 的初始值是 0（虚拟 a_0 = 0），不是 1。
  4. M 里的 D[a_i] 必须是"上一位处理完之后的真实值"：惰性写法里是 D[c] + tag，在 tag += add 之前取 —— 顺序写反会错。
  5. G 的更新用 max(G + add, M)，不是 max(G, M) + add。
  6. 多组数据要清空 D[0..A]：不能用 memset(D, 0, sizeof(D))（那是 8 MB，T=10 会慢），只清 0..A；而且 NEG 必须是"够负"的值（本文用 −10¹⁸）。
  7. 别把"最靠近的同色数"理解成"如果同色就必得分"：是指"左侧最近的同色位置"，中间可以有任意多个异色。DP 的 D[v] 天然处理了这一点。
  8. 另一种常见的 35 分路线（供对照）：设 dp[i][j][0/1] = 前 i 个位置、最后的同色连续段长为 j 且颜色为 0/1 的最大答案，转移是 dp[i][j][c] = dp[i-1][j-1][c] + a_i·[a_i = ai-1]，以及 dp[i][1][c] = maxj dp[i-1][j][1-c] + a_i·[a_i = ai-1-j]。它是 O(n²)，同样是 35 分档，但思路完全不同、且难以优化到 O(n)；想拿高分建议直接走本文的"一维 D[v]"路线。

四、T4 擂台游戏（P11234）

这是本场唯一的 NOI 级题。把它放到最后写；如果只求稳，把「特殊性质 A」的 16 分拿到手就回本了。

4.1 题意

比赛规则：设共有 2^k 名选手，进行 k 轮：

  • 第 1 轮：1 号 vs 2 号、3 号 vs 4 号、……、2^k−1 号 vs 2^k 号；
  • 第 2 轮：只保留第 1 轮胜者，相邻两位再打一场；
  • ……；第 k 轮即决赛。

每场比赛先抽签得到一个数 dR,G ∈ {0,1}（第 R 轮第 G 场）：

  • d = 0 ⇒ 编号小的选手当擂主；d = 1 ⇒ 编号大的当擂主；
  • 擂主获胜 ⟺ 其能力值 a ≥ R（当前是第几轮）。也就是说胜负只和"擂主的能力值 vs 轮数"有关，与另一位选手的能力完全无关。

补充选手：小 S 陆续收到 n 位选手报名（编号按报名顺序 1..n）。设 k 是最小的使 2^k ≥ n 的非负整数，则补 2^k − n 名选手（编号排在后面），补充选手的能力值可以任取 [0, 2³¹−1] 之内的整数。求"所有可能成为总冠军的选手（包括补充选手）的编号之和"。

m 个询问：给出 c_1..c_m。对每个 c_i，考虑"只收到前 c_i 位选手报名"的情形（即 1..c_i 是能力已知的选手，后面按 2k_i ≥ c_i 补足的都是补充选手），求此时的答案 A_i。

输出：对每组测试数据输出 (1·A_1) ⊕ (2·A_2) ⊕ … ⊕ (m·A_m)（⊕ 为按位异或）。

4.4 建模：把比赛建成一棵"胜负树"（全题地基）

2^k 名选手的淘汰赛天然是一棵满二叉树：

  • 叶子从左到右是选手 1, 2, …, 2^k；
  • 每个内部节点代表一场比赛，它的左儿子子树、右儿子子树各产出一个选手来打这一场；
  • 节点在第 ℓ 层 ⟺ 这场比赛是第 ℓ 轮。

对于节点 v 的那场比赛，若 dℓ,g = 0 则左儿子的胜者是擂主，否则右儿子的胜者是擂主（因为左子树里的编号一定更小）。

对某个选手 p，考虑它从叶子一路走到根的路径。p 能成为总冠军 ⟺ 下面两个条件同时成立：

条件一：对路径上每一场"p 是擂主"的比赛（轮数为 r），都有 a_p ≥ r。
—— 因为擂主获胜的唯一条件就是 a ≥ r。

条件二：对路径上每一场"p 不是擂主"的比赛（轮数为 r），兄弟子树必须能够产出一个能力值 < r 的胜者。
—— 因为此时对手是擂主，p 要赢就必须让对手"能力 < r"；而兄弟子树的胜者是谁、能力多少，由兄弟子树内部的（补充选手的）取值决定，与 p 无关 —— 可以独立安排。

为了判定条件二，对每个子树 u 定义：

S(u) = u 的胜者可能取得的能力值集合（把能力值截断到 [0, k] 即可，因为所有比较只涉及 1..k）。

递推（设 u 所在层为 ℓ，左儿子 L、右儿子 R）：

  • 叶子：已知选手 ⇒ S = { min(a_p, k) }；补充选手 ⇒ S = {0,1,…,k}。
  • d = 0（L 是擂主）：
    S(u) = { x ∈ S(L) : x ≥ ℓ } ∪ ( S(R) 当 min S(L) < ℓ )
    —— u 的胜者要么是 L 的胜者（它是擂主，必须 ≥ ℓ），要么是 R 的胜者（此时必须存在一种安排让 L 的胜者"输"，即 L 能产出 < ℓ 的胜者）。
  • d = 1（R 是擂主）：左右互换即可。

于是条件二 ⟺ min S(兄弟) < r，整个问题变成"下标 + 集合"的判定问题。

另外注意：补充选手能力值只需在 {0,1,…,k} 中取（因为只和 1..k 比大小，"≥ k" 这一类全部等价）。这一条让暴力枚举变得可行。

档 1（12 分，测试点 1~3，n,m ≤ 8）：暴力枚举补充选手的能力

对每个询问 c：k = ⌈log₂c⌉，M = 2^k；前 c 个叶子是已知选手（能力 clamp 到 k），后 M−c 个是补充选手。枚举每个补充选手的能力 ∈ {0,…,k}（共 (k+1)M−c 种），每种跑一遍 O(M) 的模拟，把出现的冠军编号丢进 set，最后求和。

n ≤ 8 ⇒ k ≤ 3、M ≤ 8、(k+1)M−c ≤ 4⁸ = 65536，够用。

为什么这一档只需要这些：n 极小，直接把"任意取值"枚举掉，是本题唯一"无脑对"的做法，也是后面两份代码的对拍基准。

C++
// 12分：n<=8 暴力枚举补充选手能力值（只需枚举 0..k）
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
int n, m, K;
ll a[12], b[12], c[300];
char D[30][(1 << 20) + 5];                   // d 表（本题用不满，按最大开）
int ab[20];
ll solve(int cq) {
    int k = 0; while ((1 << k) < cq) k++;
    int M = 1 << k;
    for (int p = 1; p <= M; p++)
        ab[p] = (p <= cq) ? (int)min(b[p], (ll)k) : 0;
    vector<int> freePos;
    for (int p = cq + 1; p <= M; p++) freePos.push_back(p);
    set<int> winners;
    int F = freePos.size();
    ll total = 1; for (int i = 0; i < F; i++) total *= (k + 1);
    for (ll code = 0; code < total; code++) {
        ll t = code;
        for (int i = 0; i < F; i++) { ab[freePos[i]] = t % (k + 1); t /= (k + 1); }
        vector<int> cur(M);
        for (int p = 0; p < M; p++) cur[p] = p + 1;
        for (int r = 1; r <= k; r++) {
            vector<int> nxt;
            for (int g = 0; g < (1 << (k - r)); g++) {
                int L = cur[2 * g], R = cur[2 * g + 1];
                int host = (D[r][g] == '0') ? L : R;
                nxt.push_back(ab[host] >= r ? host : (host == L ? R : L));
            }
            cur = nxt;
        }
        winners.insert(cur[0]);
    }
    ll s = 0; for (int w : winners) s += w;
    return s;
}
int main() {
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; i++) scanf("%lld", &a[i]);
    for (int i = 1; i <= m; i++) scanf("%lld", &c[i]);
    for (K = 0; (1 << K) < n; K++);
    for (int r = 1; r <= K; r++) scanf("%s", D[r]);
    int T; scanf("%d", &T);
    while (T--) {
        ll X[4];
        for (int i = 0; i < 4; i++) scanf("%lld", &X[i]);
        for (int i = 1; i <= n; i++) b[i] = a[i] ^ X[i % 4];
        ll out = 0;
        for (int i = 1; i <= m; i++) out ^= (ll)i * solve((int)c[i]);
        printf("%lld\n", out);
    }
    return 0;
}

档 2（补到 20 / 28 分，测试点 4~5 与 11~12，特殊性质 A）：全已知 ⇒ 唯一冠军

若 c_i 是 2 的幂，则 2k_i = c_i，恰好不需要补充选手，所有能力值都已知 ⇒ 整场比赛的结果唯一确定 ⇒ "可能冠军"只有一个，答案就是那个冠军的编号。

所以只要模拟一遍即可。又因为 c 是 2 的幂、c ≤ n ≤ 10⁵ ⇒ 可能的 c 只有 1,2,4,…,2^K（≤ 17 个），每个规模模拟 O(c) 一遍，总 O(n)。

档 3（补到 40 分，测试点 1~10）：条件一 / 条件二 + 子树集合 S(u)

直接用 4.4 的两条判定：

  1. 自底向上算出每个节点的 S(u)（用 bitmask，因为 k ≤ 17，一个 int 就够）；
  2. 对每个叶子 p，从叶子往根走一遍，检查条件一、条件二；

        ll out = 0;
        for (int qi = 1; qi <= m; qi++) {
            int cq = (int)c[qi];
            int k = 0; while ((1 << k) < cq) k++;
            int M = 1 << k;
            for (int d = k; d >= 0; d--) {                       // 自底向上算 S(u)
                int st = 1 << d;
                for (int u = st; u < (st << 1); u++) {
                    if (d == k) {                                // 叶子
                        int p = u - st + 1;
                        if (p <= cq) Sarr[u] = 1 << (int)min(b[p], (ll)k);
                        else Sarr[u] = (2 << k) - 1;              // 补充选手: {0..k}
                    } else {
                        int lev = k - d, g = u - st;
                        int SL = Sarr[u << 1], SR = Sarr[u << 1 | 1];
                        int lowL = __builtin_ctz(SL), lowR = __builtin_ctz(SR);
                        int hiMask = ((2 << k) - 1) ^ ((1 << lev) - 1);
                        int A, B = 0;
                        if (D[lev][g] == '0') { A = SL & hiMask; if (lowL < lev) B = SR; }
                        else                  { A = SR & hiMask; if (lowR < lev) B = SL; }
                        Sarr[u] = A | B;
                    }
                }
            }
            ll s = 0;
            for (int p = 1; p <= M; p++) {                        // 逐个检查条件一/二
                bool ok = true;
                int u = M + (p - 1);
                ll ap = (p <= cq) ? b[p] : (ll)k;                 // 补充选手可设成 k
                for (int d = k - 1; d >= 0 && ok; d--) {
                    int lev = k - d, parent = u >> 1;
                    int g = parent - (1 << d);
                    int isLeft = ((u & 1) == 0);
                    int sib = isLeft ? (u + 1) : (u - 1);
                    bool pHost = (isLeft && D[lev][g] == '0') || (!isLeft && D[lev][g] == '1');
                    if (pHost) { if (ap < lev) ok = false; }                       // 条件一
                    else       { if (__builtin_ctz(Sarr[sib]) >= lev) ok = false; } // 条件二
                    u = parent;
                }
                if (ok) s += p;
            }
            out ^= (ll)qi * s;
        }
        printf("%lld\n", out);
    }
    return 0;
}

注意：这份代码对每个询问都重建整棵树（用"堆式编号"：根为 1，儿子 2u/2u+1，叶子从 2^k 开始）。它过不了 9、10 号点以外的 10⁵ 数据，但能稳拿测试点 1~10（40 分）。

档 4（100 分）：拆贡献 + 每个点只删一次

40 分档的瓶颈是"每个询问重建一棵树、每个叶子都从下往上跳一遍"。正解的想法是反过来算：不去问"每个 c 有哪些可能冠军"，而是问"每个叶子能对哪些 c 产生贡献"。

两个关键观察：

  1. 把补充选手当作"永远认输"：规定补充选手总是把胜利让给已知选手。这样整棵树的结果是唯一确定的，于是可以给每个叶子算出一个关键点：从叶子往上，第一个"自己是擂主、但轮数已经超过自己能力"的位置（若一直是擂主且能力都够，则没有关键点）。对手只要能"可能输"（兄弟子树里有方案让对方输掉），这个叶子就能继续往上升。
  2. 贡献是一段区间：
    • 已知选手：它一直是已知的 ⇒ 随 c 变大只会更有利 ⇒ 它的贡献是 [1, 某个上界] 的一段；
    • 补充选手：它一直是补充的 ⇒ 随 c 变小只会更有利 ⇒ 它的贡献是 [1, 某个上界] 的一段。
      于是每个叶子的贡献可以用差分合并，再用一次扫描求出所有 c 的答案。

实现上用一个"每个点只被删除一次"的机制：维护 LIVE[u]（子树里还有没有"可输的方案"）与 CNT[u]（以 u 为关键点的叶子数），当某个擂主子树的兄弟整棵都失去"可输方案"时，就把兄弟整棵删掉（Remove），删除时顺手把里面的叶子从答案里扣掉。因为每个点只删一次，复杂度是 O(n)（可以证明：第 R 层的"左子树"只会访问 2^R 个点，对 R 求和恰好是 n）。

4.6 完整正解代码

C++
// T4 擂台游戏 P11234 -- 100分正解（O(T(n+m)) 拆贡献）
// 1) 建"胜负树"：2^K 个叶子，HOST[u] 表示 u 是否是父节点那场比赛的擂主
// 2) 关键点 KP：从叶子往上，第一个"自己是擂主、但轮数已超过自己能力"的位置
// 3) 每个叶子贡献一段 [1, maxc]；用 BUCKET[层号] + DEAD/LIVE 标记做到"每点只删一次"
// 4) 扫描 i=1..n 增量维护 ans（当前 c=i 的答案），SAVE[c] 即该 c 的答案
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int LIM = 200100;                 // n,m <= 1e5
const int ANC = 10010;                  // 不会用到的哨兵层号
int n, m, K, T;
ll A0[LIM], AB[LIM], Q[LIM], Xv[4];
ll LV[LIM << 2], KEY[LIM << 2], KP[LIM << 2], CNT[LIM << 2];
bool HOST[LIM << 2], DEAD[LIM << 2], LIVE[LIM << 2], USED[LIM << 2];
char D[32][LIM << 2];
int LAST;                               // 叶子编号区间 = [LAST+1, 2*LAST+1]
ll ans, out, SAVE[LIM], B;              // B: 当前扫描到的 k(c)
vector<ll> BUCKET[LIM];                 // BUCKET[level] = 关键点层号为 level 的叶子

void build(int u) {                     // 建树：层号 LV / 是否擂主 HOST
    LV[u] = 1; LIVE[u] = 1; USED[u] = CNT[u] = DEAD[u] = 0;
    if (u <= LAST) { build(u << 1); build(u << 1 | 1); LV[u] = LV[u << 1] + 1; }
    int g = (u - (1 << (K - LV[u] + 1))) >> 1;      // 这场比赛在所在轮的编号
    if (u & 1) HOST[u] = (D[LV[u]][g] == '1');      // 右儿子当擂主 <=> d=1
    else       HOST[u] = (D[LV[u]][g] == '0');      // 左儿子当擂主 <=> d=0
}
void dfs(int u) {                       // KEY[l] = 层号 >= l 的最近的擂主祖先
    if (HOST[u]) KEY[LV[u]] = u;
    else         KEY[LV[u]] = KEY[LV[u] + 1];
    if (u > LAST) { KP[u] = KEY[min(AB[u - LAST] + 1, (ll)LIM + 1)]; return; }
    dfs(u << 1); dfs(u << 1 | 1);
}
void Remove(int u, ll id) {             // 整棵删掉
    if (DEAD[u]) return;
    DEAD[u] = 1; LIVE[u] = 0;
    if (u > LAST) {
        ll kp = KP[u];
        if (u - LAST <= (1 << B) && !USED[u]) ans -= (u - LAST);
        if (u - LAST <= id) CNT[kp]--;
    }
    if (u <= LAST) Remove(u << 1, id), Remove(u << 1 | 1, id);
}
void update(int u, ll id) {             // 自底向上维护；对手整棵都"不可能输"时删掉它
    if (!LIVE[u] || !u) return;
    LIVE[u] = LIVE[u << 1] | LIVE[u << 1 | 1];
    if (!LIVE[u] && !CNT[u] && HOST[u] && !DEAD[u]) Remove(u ^ 1, id);
    if (!LIVE[u]) update(u >> 1, id);
}
int main() {
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; i++) scanf("%lld", &A0[i]);
    for (int i = 1; i <= m; i++) scanf("%lld", &Q[i]);
    for (K = 0; (1 << K) < n; K++);
    LAST = (1 << K) - 1;
    for (int r = 1; r <= K; r++)
        for (int g = 0; g < (1 << (K - r)); g++) scanf(" %c", &D[r][g]);
    scanf("%d", &T);
    LV[0] = ANC;
    while (T--) {
        build(1);
        for (int i = 0; i < 4; i++) scanf("%lld", &Xv[i]);
        for (int i = 1; i <= n; i++) AB[i] = A0[i] ^ Xv[i % 4];
        B = 0; ans = 1;
        dfs(1);
        for (int i = 1; i <= n; i++) {
            if ((1 << B) < i) {                       // c 跨过 2 的幂：先收编新叶子
                B++;
                for (int j = i; j <= (1 << B); j++) ans += (ll)j * (!DEAD[LAST + j]);
                for (size_t t = 0; t < BUCKET[B].size(); t++) {
                    ll v = BUCKET[B][t];
                    if (!DEAD[v] && !USED[v]) { ans -= v - LAST; USED[v] = DEAD[v] = 1; }
                }
            }
            if (!DEAD[LAST + i]) {                    // 第 i 个叶子由"补充"变"已知"
                ll kp = KP[LAST + i];
                BUCKET[LV[kp]].push_back(LAST + i); CNT[kp]++;
                update(LAST + i, i);
                if (LV[kp] <= B) { ans -= i; USED[LAST + i] = 1; }
            }
            SAVE[i] = ans;
        }
        for (int i = 1; i <= K; i++) vector<ll>().swap(BUCKET[i]);
        vector<ll>().swap(BUCKET[ANC]);
        out = 0;
        for (int i = 1; i <= m; i++) out ^= (ll)i * SAVE[Q[i]];
        printf("%lld\n", out);
    }
    return 0;
}

4.7 易错点

  1. 输入格式：d 表的每一行是一长串无空格的 0/1（第 R 行有 2K-R 个字符），用 scanf("%s") 或 getchar 读；用 cin >> int 会直接错。
  2. 异或下标：a_i = a'_i ⊕ Xi mod 4，i mod 4 是 0..3（i 从 1 开始：i=1 用 X1，i=4 用 X0）。
  3. 输出是"异或和"：⊕i=1..m (i · A_i)，不是求和、也不是逐行输出。
  4. 补充选手也计入答案：题目明确说"如果补充的选手有可能获胜，也应当计入答案"。
  5. 能力值比较只需 [0,k]：暴力枚举时把补充选手的能力限制在 {0,…,k} 是正确的（所有比较都是"vs 轮数 r ≤ k"）；但把已知选手的能力截断成 min(a,k) 也是正确的，不要担心丢失信息。
  6. k 与 K 的区别：K = ⌈log₂n⌉ 是整棵完整树的高度（d 表按 K 给）；每个询问的 k = ⌈log₂c_i⌉ ≤ K，用的是 d 表的前 k 行、每行前 2k-r 个字符（即完整树最左边的子树）。
  7. c = 1 要单独处理：只有 1 位选手时没有比赛，答案恒为 1（正解里 ans 的初值就是 1）。
  8. 别用 int 存答案：最大答案是 Σ i ≈ (10⁵)²/2 ≈ 5×10⁹，int 会溢出。
  9. 调试建议：先把 T 组数据当"独立小数据"用暴力跑通，再上正解；本题 90% 的"WA"其实是输入解析或异或写错。
