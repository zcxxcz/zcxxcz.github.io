# 角楼 · 建筑手记

2026-11-11 查阅。对象为故宫东北角楼；所有场景内容由代码生成，无摄影贴图、外部模型或 AI 生成图片。

## 第一手资料

- [故宫博物院《角楼》](https://www.dpm.org.cn/explore/building/236522.html)：三重檐复合歇山、十字平面、8.73 m 中厅、城外 1.60 m / 城内 3.98 m 抱厦、27.50 m 总高；上檐七踩、中下檐五踩斗拱、旋纹彩画与菱花隔扇的参考。
- [高甜《故宫西南角楼明、清瓦件对比》，《故宫学刊》2014，241 页起](https://www.dpm.org.cn/Uploads/File/2020/02/19/u5e4d00111f849.pdf)：第 241 页（PDF 第 3 页）的角楼屋顶平面、侧立面实拍、东北角楼宝顶与金刚戗脊近照；据此组织中央屋顶和四面抱厦，参考釉瓦和吻兽轮廓。方位按东北角楼调整，城内抱厦沿负 X / 负 Z，城外沿正 X / 正 Z。
- [故宫博物院刊物角楼构造资料](https://www.dpm.org.cn/Uploads/File/pdf/ad/e0/be/ade0be6221b917ee0c05c58ff2173042.pdf)：三层翼角与七十二条脊的计数参考。

## 模型范围

- 三重檐分别生成中央腰檐 / 四面抱厦 / 顶部十字歇山；内侧大抱厦将正脊转向、檐面朝城内，外侧小抱厦山面朝外，共十个山花，曲面函数建立起翘；逐列瓦垄独立起伏，几何法线形成釉面高光。
- 72 个独立脊线对象：下檐 24、中檐 32、上檐 16。按角脊、围脊、正脊、山花垂脊组织；这是面向浏览器的简化拓扑划分，并非文物测绘中对每一条脊的精确逐件编号。可高亮核对。
- 斗拱以叠斗、横拱、出昂的几何组合表现层次，纹样按青绿金线的旋纹语汇程序绘制；吻兽、菱花格扇与石栏有视觉简化。
- 中厅与四面抱厦的平面以公开尺度设定，整体高度按 27.5 m 归一；屋面曲率、柱径、构件位置和护城河场景为视觉近似，非测绘级复原。
- 清晨、黄昏和雪夜为艺术化光照；雪夜宫灯为交互氛围设计。昼夜不对应天文模拟、真实运营照明或历史原状。
- 护城河实时平面反射来自同一个三维场景，叠加程序波纹。雪粒、屋顶积雪、木作和砖缝均由代码生成。

## 运行和依赖

Three.js 0.181.2（MIT，许可证在 vendor/LICENSE-three.txt），包括同版 OrbitControls 与 Reflector。库随页面本地提供，不依赖公共 CDN。WebGL 2，现代桌面与移动浏览器；不需构建独立应用、不需账号。此静态作品随总入口构建发布。

支持鼠标 / 触屏拖动、滚轮 / 双指缩放、方向键、加减号，48 秒环绕一周；用户拖动会停止自动环绕。遵循减少动态效果偏好，停用自动雪粒与水波运动（用户主动开启环游仍可使用）。
