一、T2 消消乐（P9753）

1.1 题意

给定长度 n 的小写字符串 s。一次操作可删除相邻且相同的两个字符，删除后两边拼接。称一个串"可消除"当且仅当能通过若干次操作变成空串。求 s 有多少个非空连续子串是可消除的。

样例：8 / accabccb → 5（分别是 cc、acca、cc、bccb、accabccb）。

1.2 数据范围与子任务

1 ≤ n ≤ 2×10⁶；字符集为小写字母。

测试点 n ≤ 特殊性质 分值
1~5 10 无 25
6~7 800 无 10
8~10 8000 无 15
11~12 2×10⁵ A：每个字符独立等概率随机选取 10
13~14 2×10⁵ B：串只由 a、b 构成 10
15~17 2×10⁵ 无 15
18~20 2×10⁶ 无 15

1.3 两个核心引理（全题地基）

把"相邻相同即抵消"的消除规则看成一个栈：从左到右扫，若当前字符与栈顶相同就弹出，否则压入。记 R_i = 扫描完前 i 个字符后栈里的内容（称作前缀 i 的归约状态）。

引理 1（归约唯一性）：消除的先后顺序不影响最终剩下的串。也就是说 R_i 定义良好。 直觉证明：把每个字符看作自由群（每个生成元满足 a²=e）中的元素，"相邻相同抵消"就是该群的唯一正规形式；归约映射 reduce 是幺半群同态，reduce(uv) = reduce(u)·reduce(v)。

引理 2（关键）：子串 s[l..r] 可消除 ⟺ R_{l-1} = R_r。

证明（两行）：

  • 若 s[l..r] 可消除，则 R_r = reduce(R_{l-1} · s[l..r]) = R_{l-1} · reduce(s[l..r]) = R_{l-1} · ε = R_{l-1}。
  • 反之若 R_r = R_{l-1}，由 R_r = R_{l-1} · reduce(s[l..r]) 两边左乘 R_{l-1}^{-1}（自由积里每个元素都是自逆的）得 reduce(s[l..r]) = ε。

于是答案 = 满足 0 ≤ l-1 < r ≤ n 且 R_{l-1} = R_r 的下标对数 = Σ 每种状态下标数 C(cnt, 2)。

1.4 一档一档来

档 1（25 分，n ≤ 10）：O(n³) 暴力

枚举左右端点 [l, r]，用栈模拟判断是否可消，O(n) 判定 × O(n²) 区间 = O(n³)。n=10 随便过。

C++
// 只写核心：对每个区间用栈判定
bool ok(const string& s, int l, int r) {
    string st;
    for (int i = l; i <= r; i++) {
        if (!st.empty() && st.back() == s[i]) st.pop_back();
        else st.push_back(s[i]);
    }
    return st.empty();
}

档 2（35 分，n ≤ 800）：O(n³) 稍作优化 / O(n²) 起步

n=800 时 n³=5×10⁸ 用 std::string 会 TLE，改成 vector<char> 或提前剪枝就能过。

档 3（50 分，n ≤ 8000）：O(n²) 定右端点、向左扩展

观察：固定右端点 r，把左端点 l 从 r 递减到 0 时，reduced(s[l..r]) 可以通过在最前面插入一个字符从 reduced(s[l+1..r]) 得到：若首字符等于 s[l] 就删掉首字符，否则把 s[l] 放到最前面。所以一个右端点只需 O(n) 维护。

实现上把"归约结果"倒序存进 vector<char>，那么"删首字符/插首字符"就变成 pop_back / push_back。

C++
// 50 分：O(n^2)
int main() {
    int n; string s; cin >> n >> s;
    long long ans = 0;
    vector<char> st;
    for (int r = 0; r < n; r++) {
        st.clear();
        for (int l = r; l >= 0; l--) {
            if (!st.empty() && st.back() == s[l]) st.pop_back();  // 倒序存，back 就是首字符
            else st.push_back(s[l]);
            if (st.empty()) ans++;     // s[l..r] 可消除
        }
    }
    cout << ans << "\n";
}

n=8000 时 6.4×10⁷ 次操作，稳稳过（1~10 号点全部拿下 = 50 分）。

档 4（60 分）：把它变成 DP（思路升级，复杂度暂不变）

设 f[i] = 以 i 结尾的可消除子串个数。设 j 是使 s[j+1..i] 可消除的最大的 j（即最短的可消后缀的左边界-1），则

文本
f[i] = f[j] + 1     （找到则转移，找不到 f[i] = 0）
答案 = Σ f[i]

为什么对：所有以 i 结尾的可消子串中，最短的那个是 [j+1, i]；对任何更短的 [t+1, i]（t < j），由引理 2 有 R_t = R_i = R_j，即 s[t+1..j] 也可消 —— 于是它们与"以 j 结尾的可消子串"一一对应。

C++
// 60 分：O(n^2) 的 DP（从右往左扫 j 找最短可消后缀）
for (int i = 1; i <= n; i++) {
    vector<char> st; f[i] = 0;
    for (int j = i - 1; j >= 0; j--) {
        if (!st.empty() && st.back() == s[j]) st.pop_back();
        else st.push_back(s[j]);
        if (st.empty()) { f[i] = f[j] + 1; break; }
    }
    ans += f[i];
}

档 5~6（85 → 100 分）：直接用"状态"计数

上面 O(n²) 的瓶颈是"每次都要向左重扫一遍"。改成在线维护状态：从 i=1 扫到 n，每一步只做一次压栈/弹栈，得到当前状态编号；答案累加"这个状态之前出现过几次"。

难点：状态是一个字符串，怎么快速表示？两条路——

  1. 双哈希/自然溢出哈希：把栈内容哈希，用 map/unordered_map 统计每个哈希值出现次数，Σ C(cnt,2)。注意单模数（如 998244353、10⁹+7）在 n=2×10⁶ 时冲突概率很大，必须用自然溢出（unsigned long long）或双哈希。
  2. 字典树（推荐，无冲突风险）：每个状态 = 字典树上一个结点。压入字符 c 就是"从当前结点走字符 c 的儿子"；弹出就是"回到父亲"。每个结点对应唯一的一个归约串，所以状态相同 ⟺ 结点编号相同，彻底不用怕哈希冲突。

把"最短路 DP"和"字典树"合起来写，就是最终 O(n) 解：

C++
// P9753 满分 O(n)
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; string s;
    if (!(cin >> n)) return 0;
    cin >> s;

    vector<int> par(1, -1);      // 结点 = 归约状态；par = 弹出后回到的状态
    vector<char> chr(1, 0);      // 到达该状态时压入的字符 = 栈顶字符
    vector<int> lastSeen(1, 0);  // 该状态最近一次出现的前缀下标（状态 0 在 i=0 出现过）
    vector<long long> f(n + 1, 0);
    unordered_map<long long, int> to;
    to.reserve((size_t)n * 2 + 16);   // 关键！不 reserve 会反复 rehash，慢且费内存
    to.max_load_factor(0.7);

    int cur = 0;
    long long ans = 0;
    for (int i = 1; i <= n; i++) {
        int c = s[i - 1] - 'a';
        if (cur != 0 && chr[cur] == s[i - 1]) {
            cur = par[cur];                       // 与栈顶相同 -> 弹出
        } else {
            long long key = (long long)cur * 26 + c;
            auto it = to.find(key);
            if (it == to.end()) {                 // 压入并新建结点
                int id = (int)par.size();
                par.push_back(cur); chr.push_back(s[i - 1]); lastSeen.push_back(-1);
                to.emplace(key, id); cur = id;
            } else cur = it->second;
        }
        int p = lastSeen[cur];
        long long fi = (p >= 0 ? f[p] + 1 : 0);
        f[i] = fi; ans += fi;
        lastSeen[cur] = i;
    }
    cout << ans << "\n";
}

实测：n=2×10⁶ 随机串 0.15 s / 148 MB；全 a 串输出 1000000000000（= 10¹²，与"偶数长度子串个数 = (n/2)²"完全吻合）0.07 s / 55 MB。内存/时间都在 512 MB / 1 s 内很宽松。

1.5 T2 易错点

  1. 答案范围：n=2×10⁶ 时答案可达 ~10¹²，必须 long long（int 直接爆）。
  2. 哈希：单模数会被卡；要么自然溢出，要么双哈希，要么字典树。用 unordered_map 一定要 reserve（有人不 reserve 直接 MLE 90 分）。
  3. 弹栈只弹一次：因为"压入前栈是归约状态（无相邻相同）"，压入后最多只有栈顶一对相同，弹完就恢复归约性，不需要 while。
  4. 两种视角等价：Σ C(cnt,2) 和 Σ f[i]（f[i]=f[prev]+1）算的是同一个东西，任选其一。

二、T3 结构体（P9754）

2.1 题意与对齐规则（逐条翻译成公式）

基本类型（大小 = 对齐要求）：byte 1、short 2、int 4、long 8。

  • 结构体类型的对齐要求 = 所有成员的对齐要求的最大值。
  • 结构体内部成员按定义顺序排布。设该结构体成员大小 s_1..s_k、对齐 a_1..a_k，偏移量 o_1..o_k：
    • o_1 = 0；
    • o_j（j≥2）= 满足 o_j > o_{j-1} + s_{j-1} - 1 且 a_j | o_j 的最小值；
    • 结构体大小 = 满足 size > o_k + s_k - 1 且 align | size 的最小值。
  • 顶层元素同理：第 1 个元素起始地址 0，之后每个元素 start_i = 满足 start_i > end_{i-1} 且能被自己对齐要求整除的最小值。

一句话记法：把"已用字节数"记为 used（即下一个空闲字节的下标），则

C++
ll alignUp(ll x, ll a) { return (x + a - 1) / a * a; }
// 成员偏移 / 元素起始：off = alignUp(used, 该成员自己的对齐要求);
// 结构体大小：        size = alignUp(used, 结构体自身的对齐要求);   ← 只有这一步用结构体的对齐

这里就是最大的坑：成员只按自己的对齐要求对齐（int 成员就要对齐到 4，哪怕整个结构体对齐要求是 8）；只有整个结构体的大小才向上取整到结构体的对齐要求。

例子：struct d { short a; int b; short c; }; d e; a 占 0~1，b 对齐到 4 占 4~7，c 占 8~9，已用 10 字节；结构体对齐要求 = max(2,4,2) = 4，向上取整 → size = 12。 所以第 2~3、10~11 字节是洞，里面没有任何基本类型元素 → 操作 4 要输出 ERR。

2.2 数据范围与子任务

n ≤ 100，k ≤ 100，0 ≤ addr ≤ 10¹⁸；名字均为 ≤10 个小写字母，且不与基本类型重名。

测试点 特殊性质 分值 累计
1 A、D 5 5
2~3 A 10 15
4~5 B、D 10 25
6~8 B 15 40
9~10 C、D 10 50

  • A：没有操作 1（不定义结构体类型）→ 所有元素都是基本类型，操作 3 的 s 里根本不会出现 .。
  • B：只有一个操作 1 → 类型图深度最多 2（元素 → 该结构体 → 基本类型），可以把"下降一层"写死。
  • C：所有操作 1 的成员类型均为基本类型 → 结构体内部没有嵌套，但元素可以是结构体（深度 1）。
  • D：基本类型只有 long → 所有大小/对齐都是 8 的倍数 ⇒ 永远不会产生对齐空洞，操作 4 不会出 ERR（除越界），地址计算退化成"每层 ×8"。

难点 涉及测试点

  • 25 分（+B、D）：只有一个结构体，下降深度 ≤ 2。
  • 40 分（+B）：同上。
  • 50 分（+C、D）：一层结构体 + 无洞，最简单的一种"有结构体"情形。
  • 65 分（+C）：一层结构体 + 有洞（第一次需要写 ERR 判定）。

2.3 数据结构（一次写好，各档共用）

  • 结构体类型不是元素，不占内存；元素数量最多 k 个、类型最多几个，而"实际存在的叶子"可能是指数级 —— 所以绝不能真的把元素展开，必须"按需下降"。
  • 只用 vector + unordered_map，不用指针也能写得很干净：
C++
struct Member { string name; int type; ll off; };   // off = 相对本结构体起始的偏移
struct Type   { ll size=0, align=1; vector<Member> mem; unordered_map<string,int> idx; };
struct Elem   { string name; int type; ll start; };

types[0..3] 预置为四种基本类型（size = align = 1/2/4/8，成员表为空）。判断"是不是叶子"就看 type < 4。

2.4 四个操作的具体写法

  • 操作 1（定义类型）：used = 0；对每个成员 off = alignUp(used, align(成员类型))，used = off + size(成员类型)，同时更新 align = max(align, align(成员类型))；最后 size = alignUp(used, align)。输出 size align。
  • 操作 2（定义元素）：start = alignUp(已用全局字节数, align(元素类型))，然后 已用 = start + size(元素类型)。输出 start。
  • 操作 3（a.b.c 访问）：按 . 切成 token，第一个 token 是元素名（在全局元素表里查），后面每个 token 是上一层的成员名；一路 addr += 成员偏移，最后输出 addr。
  • 操作 4（按地址反查）：先在顶层元素里找"包含 addr"的那个（元素按起始地址有序，边扫边判；若 addr 比当前元素起点还小 → 说明落在元素之间的洞里 → ERR，扫完都没有 → 越界 → ERR）。 然后进入该元素内部逐层下降：在 [off, off+size-1] 里找包含 local 的成员；若 local 比某个成员的偏移还小，说明落在结构体内部的洞里 → ERR。一直下降到 type < 4（基本类型）为止，把走过的成员名用 . 拼起来输出。

2.5 完整代码（100 分，已实测）

C++
// P9754 结构体 —— 大模拟（满分写法）
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

struct Member { string name; int type; ll off; };
struct Type {
    ll size = 0, align = 1;
    vector<Member> mem;
    unordered_map<string, int> idx;
};
struct Elem { string name; int type; ll start; };

static inline ll alignUp(ll x, ll a) { return (x + a - 1) / a * a; }

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n; if (!(cin >> n)) return 0;

    vector<Type> T(4);
    const char *bn[4] = {"byte", "short", "int", "long"};
    ll bs[4] = {1, 2, 4, 8};
    unordered_map<string, int> tid;
    for (int i = 0; i < 4; i++) { T[i].size = T[i].align = bs[i]; tid[bn[i]] = i; }

    vector<Elem> elems;
    ll curMem = 0;

    while (n--) {
        int op; cin >> op;
        if (op == 1) {                            // 定义结构体类型
            string s; int k; cin >> s >> k;
            Type t; t.align = 1; ll used = 0;     // used = 下一个空闲字节
            for (int j = 0; j < k; j++) {
                string tn, mn; cin >> tn >> mn;
                int ti = tid[tn];
                ll off = alignUp(used, T[ti].align);   // 只按成员自身的对齐要求
                t.mem.push_back({mn, ti, off});
                used = off + T[ti].size;
                t.align = max(t.align, T[ti].align);
            }
            t.size = alignUp(used, t.align);      // 整体大小对齐到结构体对齐要求
            for (int j = 0; j < k; j++) t.idx[t.mem[j].name] = j;
            tid[s] = (int)T.size(); T.push_back(t);
            cout << t.size << ' ' << t.align << '\n';
        } else if (op == 2) {                     // 定义元素
            string tn, mn; cin >> tn >> mn;
            int ti = tid[tn];
            ll start = alignUp(curMem, T[ti].align);
            elems.push_back({mn, ti, start});
            curMem = start + T[ti].size;
            cout << start << '\n';
        } else if (op == 3) {                     // a.b.c 访问
            string s; cin >> s;
            vector<string> tok; string cw;
            for (char c : s) { if (c == '.') { tok.push_back(cw); cw.clear(); } else cw.push_back(c); }
            tok.push_back(cw);
            int ei = 0;
            for (int i = 0; i < (int)elems.size(); i++)
                if (elems[i].name == tok[0]) { ei = i; break; }
            int ti = elems[ei].type; ll addr = elems[ei].start;
            for (int j = 1; j < (int)tok.size(); j++) {
                int mi = T[ti].idx[tok[j]];
                addr += T[ti].mem[mi].off;
                ti = T[ti].mem[mi].type;
            }
            cout << addr << '\n';
        } else {                                  // 按地址反查
            ll addr; cin >> addr;
            int ei = -1;
            for (int i = 0; i < (int)elems.size(); i++) {
                ll st = elems[i].start, en = st + T[elems[i].type].size - 1;
                if (addr < st) break;             // 落在元素之间的空洞
                if (addr <= en) { ei = i; break; }
            }
            if (ei < 0) { cout << "ERR\n"; continue; }
            ll local = addr - elems[ei].start;
            int ti = elems[ei].type;
            string path = elems[ei].name;
            bool ok = true;
            while (ti >= 4) {                     // 0~3 是基本类型 = 叶子
                int mi = -1;
                for (int j = 0; j < (int)T[ti].mem.size(); j++) {
                    ll o = T[ti].mem[j].off, sz = T[T[ti].mem[j].type].size;
                    if (local < o) break;         // 洞
                    if (local <= o + sz - 1) { mi = j; break; }
                }
                if (mi < 0) { ok = false; break; }
                path += "." + T[ti].mem[mi].name;
                local -= T[ti].mem[mi].off;
                ti = T[ti].mem[mi].type;
            }
            cout << (ok ? path : string("ERR")) << '\n';
        }
    }
    return 0;
}

2.6 T3 易错点清单

  1. 成员对齐 ≠ 结构体对齐（最常见 WA）：成员只按自己要求对齐；只有整体大小向上取整。
  2. ERR 的三种来源：① addr 超过已分配最大地址；② 落在两个顶层元素之间的洞；③ 落在结构体成员之间的洞。
  3. 不要把元素展开：叶子数量可达指数级，必须"按需下降"。
  4. 溢出：addr 到 10¹⁸，alignUp 里 x + a - 1 不会溢出（10¹⁸ + 7 < 9.2×10¹⁸），但所有涉及的量都要 long long；int 必爆。
  5. 操作 3 输出的是"最内层元素的起始地址"，不是大小；操作 4 输出的路径要从顶层元素名开始逐级拼。
  6. 三种名字可能重名（不同结构体之间），所以类型名 → 类型的映射和成员名 → 成员的映射要在各自作用域里查，不要共用一个全局 map。
  7. D 档（只有 long）虽然简单，但别写成"所有偏移都乘 8 就完事"—— 嵌套层级要正确逐层累加。

三、T4 种树（P9755）

3.1 题意

n 个地块构成一棵树，1 号是入口（根）。第 1 天只能在 1 号种树；此后每天可以选一个未种树且与已种树地块相邻的地块种下一棵高度为 0 的树。i 号地块的树若在第 x 天种下，则从第 x 天起每天长高 max(b_i + k·c_i, 1) 米（k 是全局天数，不是种下后的第几天）。要求每棵树高度 ≥ a_i，求最少天数。

样例：n=4，(a,b,c) = (12,1,1), (2,4,-1), (10,3,0), (7,10,-2)，边 1-2, 1-3, 3-4 → 答案 5（顺序 1(第1天) → 3(第2天) → 4(第3天) → 2(第4天)）。

3.2 数据范围与子任务

1 ≤ n ≤ 10⁵，1 ≤ a_i ≤ 10¹⁸，1 ≤ b_i ≤ 10⁹，|c_i| ≤ 10⁹；保证存在方案能在 10⁹ 天内完成。

测试点 n ≤ 特殊性质 分值 累计
1 20 A 5 5
2~4 20 无 15 20
5~6 500 A 10 30
7~8 10⁵ A 10 40
9~10 10⁵ B 10 50
11~13 10⁵ C 15 65
14~16 10⁵ D 15 80
17~20 10⁵ 无 20 100
  • A：所有 c_i = 0 → 每天长 b_i（≥1），种下的时间不影响"需要多少天"。
  • B：u_i = i, v_i = i+1 → 树就是链 1−2−3−…−n，且 1 是端点 ⇒ 种树顺序被唯一确定（第 i 天种 i 号点）。
  • C：每个点度数 ≤ 2 → 树还是一条链，但标号任意（根 1 可能落在链中间 → 两条支链）。
  • D：u_i = 1 → 菊花图，只有根受"必须先种"的约束，其余点随便种。

3.3 两个关键引理

引理 1：每天至少长 1 米 ⇒ 一定存在最优方案在前 n 天每天种一棵（种完 n 棵后原地等它们长）。理由：把空闲日期的后续种植整体前移，高度只会增加，先后约束也不会破坏。 ⇒ 于是"种树方案"就是一个 1..n 天到结点的双射，且满足"父亲比儿子先种"（树的拓扑序）。

引理 2：若 t 天可行，则 t+1 天也可行（树不会缩水）⇒ 答案可二分。

于是整个问题是：二分答案 t → 对每个点算出"最晚种植时间" d_u → 判断"是否存在拓扑序 π 使 π(u) ≤ d_u"。

3.4 计算函数：给定 t，某点最晚第几天种？

设 gain(i, x, t) = 第 x 天种下、到第 t 天一共长了多少：

  • c_i ≥ 0：每一项都是 b_i + k·c_i ≥ 1，是等差数列： gain = (t-x+1)·b_i + c_i·(x+t)(t-x+1)/2
  • c_i < 0：b_i + k·c_i ≥ 1 ⟺ k ≤ ti = ⌊(b_i-1)/(-c_i)⌋。
    • 若 x > ti：全程每项都是 1，gain = t-x+1；
    • 否则令 hi = min(ti, t)：前 (hi-x+1) 天走等差数列，之后每天 +1。

d_i(t) = 使 gain(i, x, t) ≥ a_i 成立的最大 x（关于 x 单调，所以内层再二分）。x 只需在 [1, n] 里二分（由引理 1，种植只用前 n 天；求不到就说明这个 t 不可行）。

数值范围：gain 最大可达 ~10²⁷ 级别（b·t·t），必须用 __int128。

3.5 一档一档来

档 1（20 分，n ≤ 20）：状压 DP

直接算答案，不二分：need(u, x) = 第 x 天种下、最少第几天能长够 a_u（对 T 二分即可）。

dp[S] = 已种下集合 S（用了前 |S| 天）时"完成天数"的最小值：

文本
dp[S] = min over u∈S, （father(u) ∈ S\{u} 或 u=1）of max( dp[S\{u}], need(u, |S|) )
答案 = dp[全集]

复杂度 O(2ⁿ·n) = 2×10⁷，一次算完，n=20 稳稳过 1~4 号点。

C++
// 核心（完整版见文末文件 t4_dp.cpp）
for (unsigned S = 1; S < (1u << n); S++) {
    int day = __builtin_popcount(S);
    for (int u = 1; u <= n; u++) {
        if (!(S >> (u-1) & 1)) continue;
        if (u != 1 && !((S >> (fa[u]-1)) & 1)) continue;   // 父亲必须先种
        unsigned P = S ^ (1u << (u-1));
        if (dp[P] == INF) continue;
        dp[S] = min(dp[S], max(dp[P], need(u, day)));
    }
}

（也可以直接 n! 枚举/DFS 剪枝枚举所有种树顺序，n≤20 的菊花图会被卡，所以推荐状压。）

档 2（40 分，+ 特殊性质 A：c_i = 0）

此时某点需要 needed_i = ⌈a_i / b_i⌉ 天，与种下的时间无关。二分答案 t 后： d_i = t - needed_i + 1（种下去之后还需要 needed_i 天，所以最晚第 t-needed_i+1 天种）。

再处理"父亲先儿子"的约束（见 3.6 第 2 步）并判定即可。

档 3（50 分，+ 特殊性质 B：链且按标号顺序）

链且 1 是端点 ⇒ 第 i 天必须种 i 号点（顺序唯一）。于是每个点独立：

文本
答案 = max_i ( 满足 gain(i, i, T) ≥ a_i 的最小 T )

对每个点二分 T 即可，O(n log V)。注意 gain 的分段/__int128。

档 4（65 分，+ 特殊性质 C：度数 ≤ 2，标号任意）

还是链，但根 1 可能在链中间 → 变成"从根出发的两条支链"。两条支链相对独立（可以交错种），可以：

  • 直接套满分框架（二分 + 截止时间 + 计数判定），完全够用；
  • 或者理解为"两条序列归并"：每一步比较两条链当前头部的最晚种植时间，先种更紧急的那个。

这档的价值：让你意识到"种树顺序不是死的，最终判据是截止时间"。

档 5（80 分，+ 特殊性质 D：菊花图）

所有点都直接连 1 ⇒ 只有 1 必须在第 1 天种，其余 n−1 个点随便排。于是"拓扑约束"消失，只剩：

文本
二分答案 t → 算每个点的 d_u → 排序：把 d 从小到大排成 d(1) ≤ d(2) ≤ ... ，检查 d(k) ≥ k

这就是"每个期限用一天"的经典调度判定。

档 6（100 分）：完整算法四步

文本
1. 二分答案 t ∈ [n, 1e9]
2. 对每个 i，在 x ∈ [1, n] 上二分求出最晚种植时间 d_i(t)   —— 用 gain(i, x, t) ≥ a_i
   （某个点求不到 d_i ≥ 1 直接判定 t 不可行）
3. 父亲必须比儿子先种 ⇒ 后序遍历，把约束往上压：
       d_u = min(d_u, min over 儿子 v of (d_v - 1))
   （后序保证儿子的 d_v 已经压完，于是能传递整条链）
4. 现在只剩"是否存在排列 π 使 π(u) ≤ d_u"：
       令 cnt[x] = #{u : d_u = x}，做前缀和 s_i = Σ_{x≤i} cnt[x]；
       若存在 i 使 s_i > i 则不可行（Hall 定理：每个 d≤i 的点只能用前 i 天里的一天）

为什么第 3 步充分：拓扑序要求祖先早于后代，把它压成 d_u ≤ d_v - 1 后，原问题恰好等价于"单纯的时间片分配"问题（Hall 条件是充要的）。 为什么不直接"按 d 排序后贪心种"：那样无法保证父亲先于儿子；所以必须先用第 3 步把拓扑约束吃掉。

C++
// P9755 种树 —— 满分（已实测）
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef __int128 lll;

int n;
vector<ll> a, b, c;
vector<vector<int>> g;
vector<int> fa, ord;      // ord = 后序遍历序
vector<int> d, cnt;

static lll gain(int i, ll x, ll t) {          // 第 x 天种，到第 t 天长了多少
    ll bi = b[i], ci = c[i];
    if (ci >= 0)
        return (lll)(2 * bi + ci * (lll)(x + t)) * (t - x + 1) / 2;
    ll ti = (bi - 1) / (-ci);                 // 最后一个 bi + k*ci >= 1 的 k
    if (x > ti) return t - x + 1;
    ll hi = min(ti, t);
    lll s = (lll)(2 * bi + ci * (lll)(x + hi)) * (hi - x + 1) / 2;
    s += (t - hi);
    return s;
}

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    if (!(cin >> n)) return 0;
    a.assign(n + 1, 0); b.assign(n + 1, 0); c.assign(n + 1, 0);
    for (int i = 1; i <= n; i++) cin >> a[i] >> b[i] >> c[i];
    g.assign(n + 1, {});
    for (int i = 1; i < n; i++) { int u, v; cin >> u >> v; g[u].push_back(v); g[v].push_back(u); }

    // 以 1 为根求后序（儿子一定排在父亲前面）
    fa.assign(n + 1, 0); ord.clear(); ord.reserve(n);
    vector<int> stk{1}, it(n + 1, 0);
    while (!stk.empty()) {
        int u = stk.back();
        if (it[u] < (int)g[u].size()) {
            int v = g[u][it[u]++];
            if (v == fa[u]) continue;
            fa[v] = u; stk.push_back(v);
        } else { ord.push_back(u); stk.pop_back(); }
    }

    d.assign(n + 1, 0); cnt.assign(n + 2, 0);

    auto chk = [&](ll t) -> bool {
        for (int i = 1; i <= n; i++) {
            int lo = 1, hi = n, res = 0;
            while (lo <= hi) {                       // 求最晚种植时间
                int mid = (lo + hi) >> 1;
                if (gain(i, mid, t) >= a[i]) { res = mid; lo = mid + 1; }
                else hi = mid - 1;
            }
            if (res == 0) return false;
            d[i] = res;
        }
        for (int k = 0; k < n; k++) {                // 后序：拓扑约束向上压
            int u = ord[k];
            for (int v : g[u]) if (v != fa[u]) d[u] = min(d[u], d[v] - 1);
            if (d[u] <= 0) return false;
        }
        for (int i = 1; i <= n; i++) cnt[i] = 0;
        for (int i = 1; i <= n; i++) cnt[d[i]]++;
        int s = 0;
        for (int i = 1; i <= n; i++) { s += cnt[i]; if (s > i) return false; }
        return true;
    };

    ll lo = n, hi = 1000000000LL;                     // 下界 n：n 棵树至少要 n 天
    while (lo < hi) {
        ll mid = lo + (hi - lo) / 2;
        if (chk(mid)) hi = mid; else lo = mid + 1;
    }
    cout << lo << '\n';
}

实测：

  • 样例 → 5 ✓（与暴力一致）；
  • 与暴力/状压互相随机对拍 650 组 全部一致（随机树形状 + 随机 a/b/c）；
  • 边界：n=1, a=10¹⁸, b=10⁹, c=10⁹ → 44720（与手算 10⁹(T + T(T+1)/2) ≥ 10¹⁸ 完全一致，验证 __int128 无溢出）；b=10⁹,c=-10⁹,a=10⁵（全程 +1）→ 100000 ✓；
  • n=10⁵ 随机大数据 0.41 s / 10 MB。

3.6 T4 易错点

  1. 溢出：gain 内部量级到 10²⁷，必须 __int128；2*b_i + c_i*(x+t) 也要先转 __int128。
  2. 二分的下界取 n：n 棵树至少 n 天；取 1 会让 gain(i,x,t) 在 t < x 时失去意义（这也是很多"随机对拍不过"的原因）。
  3. 第 3 步必须后序：先处理儿子再处理父亲，否则约束不能沿着链传递。
  4. 第 4 步用计数而不是排序贪心：排序贪心只能得到"可行的一个必要条件"，只有 s_i ≤ i 这个 Hall 条件才是充要的（配合第 3 步）。
  5. max(b_i + k·c_i, 1) 的分段点：ti = (b_i - 1) / (-c_i) 是整除（c 为负，注意符号）；x > ti 时全是 1；hi = min(ti, t) 别漏了 min(t,·)。
  6. a_i 到 10¹⁸，读入也要 long long。
  7. D 档（菊花图）不等于"随便种"：仍要按 d 排序/计数判定，不是输出 n 就完事。

四、最后的考场取舍

题 想稳拿的分 最短路径
T2 50 → 100 O(n²) 定右端点（20 行）→ 换成"状态编号 + 最近出现"（30 行）
