01 / 时空与求解器

克尔度规，Boyer–Lindquist 坐标，几何单位 G = c = M = 1。采用 Carter 分离方程，以反向 Mino 参数、u = 1/r 和 μ = cos θ 进行四阶 Runge–Kutta 数值积分。径向和极向转向点由二阶方程自然穿过；角向运动以单位球上的向量形式积分，避开极轴坐标奇点；步长按运动频率和方位变化缩小。

R(r) = [r² + a² − aλ]² − Δ[η + (λ − a)²]
Θ(θ) = η + a²cos²θ − λ²cot²θ

相机位于 r = 80 M，以局部零角动量观测者（ZAMO）的正交标架初始化光子。拖动改变倾角和方位，缩放改变相机视场。自旋可取 −0.998 至 +0.998；盘始终沿正方位方向旋转，负自旋时属于逆行盘。

02 / 光谱与吸积盘

盘为不透明、几何薄的赤道盘，范围从对应自旋的 ISCO 到 20 M；取反向追踪中的第一个有效交点。气体按克尔圆轨道角速度 Ω = 1/(r³ᐟ² + a) 运动。频移由光子与发射体、观测者四速度的内积给出，其中 ε 为无穷远守恒能量与相机局部光子能量之比：

g = νobs / νem = 1 / [ε · uᵗ(1 − Ωλ)]
Iν,obs = g³ Iν/g,em

以普朗克谱的三个可见波长采样呈色，频率积分后的总亮度对应 g⁴。引力红移开关用 ZAMO lapse 分离静态引力部分，多普勒开关控制剩余的运动与拖曳部分；这两个开关用于对照实验，完整物理解默认全部开启。

温度采用带零应力内缘的简化薄盘径向分布 T ∝ [r⁻³(1 − √(rISCO/r))]¹ᐟ⁴。盘面纹理是随轨道流动的程序化扰动，含积分得到的传播时延。它不是磁流体模拟，也没有模拟散射、偏振、盘厚度和全谱辐射输运。曝光和屏幕颜色映射属于显示处理。

03 / 手机与精度

静止克尔时空中的光路只在视角、自旋或画质改变时重新积分。动画每帧从刚求得的盘面位置、传播时延和频移计算辐射。手机降低计算分辨率，交互时暂降采样，松手后细化；没有切换成牛顿引力模型。

流畅 / 自适应 / 高精度分别使用最多 512 / 1280 / 2560 步。步数耗尽的像素呈暗紫色，数值检验模式中为亮紫色。残差图从青色（约 10⁻⁷ 以下）到橙红色（约 10⁻² 以上），显示径向、极向势约束及角向单位向量长度的最大归一化误差。光子临界曲线附近的高阶像受有限步数和分辨率限制。

需要 WebGL 2 与浮点颜色附件支持。未在真实手机上测得帧率；页面显示的是当前设备实际绘制帧率，重新求解期间会下降。
