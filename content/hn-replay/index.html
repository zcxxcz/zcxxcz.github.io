    ABOUT THE ARCHIVE

    收录规则

    按 YouTube 视频 ID 合并同一视频的链接。收录的每部视频至少有两条来自不同 HN 用户、分属不同年份、相隔至少 365 天的直接投稿。每条列出的投稿至少 5 分，其中至少一条达到 30 分。日期按 UTC 计算。

    这是精选快照。候选来自截至 2023 年 8 月的 HN 公开存档，再用 HN Search 补查入选视频的后续投稿，并逐条用 HN 官方 API 核对。评论里的视频链接未计入。频道名称和封面来自 YouTube。
