大纲里的方括号数字，怎么读

官方《NOI 大纲》每条写成 • 【6】 分治算法，方括号里的 1–10 是掌握等级，数字越大越靠后。它给的是「阶段」，不是「该不该学」——这也是这份表要在等级之外再叠一层「近七年考没考」的原因。

【4】–【7】入门级常见区间

  • 基础算法 【6】分治
  • 排序 【5】归并 / 快速 / 堆 / 桶，【6】基数排序
  • 字符串 【4】KMP，【7】Manacher
  • 图论 【6】最小生成树、单源最短路，【7】Floyd-Warshall、强连通分量、割点割边
  • 图上路径 【7】单源次短路

【8】–【10】省选 / NOI 区间

  • 图论 【8】基环树、最小树形图、2-SAT、网络流、匈牙利，【10】KM、一般图匹配
  • 动态规划 【9】模型构建与优化
  • 初等数论 【8】原根与指数、BSGS，【9】狄利克雷卷积，【10】二次剩余
  • 线性代数 【9】逆矩阵、行列式、向量空间与线性相关、基与线性基
  • 高等数学 【8】多项式微分 / 积分，【10】泰勒级数、快速傅里叶变换
