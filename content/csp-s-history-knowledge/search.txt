贪心与构造论证 主解14 替代0 合计14 沿用主表 G 类，含交换论证、区间贪心、反悔贪心及生成树的贪心性质；不把只会背某种贪心模板视为掌握全部题。
DP 总类（去重） 主解12 替代0 合计12 包含本报告中一般 DP、背包、区间 DP、树形 DP 四个主解分桶，共 12 题；不能把总类与子类相加。组合数预处理等简单递推未全部扩张为 DP 独立专题。
其他一般 DP 主解7 替代0 合计7 为统计而设的互斥主解分桶：排除本表已单列的常规背包、区间和树形 DP；包含分段、整数划分、线性、多维数量状态、期望和计数 DP。
背包 DP（常规模型） 主解2 替代1 合计3 主解两题为《金明的预算方案》的依赖/分组背包及《货币系统》的完全背包。《数的划分》可另按完全背包加数量状态组织，列为替代增加。树形背包属于它与树形 DP 的交叉部分。
区间 DP 主解2 替代0 合计2 《能量项链》《括号序列》；《乘积最大》固定按前缀分段 DP 计，不因为出现子串预处理就重复算区间 DP。
高精度 主解2 替代0 合计2 前者涉及高精度乘法，后者涉及高精度乘/除及比较。使用 long long 或对 2^64 单独处理不自动等于学习过任意精度算法。
显式排序（辅助工具） 主解9 替代0 合计9 固定代表路线中显式排序的辅助步骤：坐标、数值、贪心顺序、映射、邻接点、事件、区间或候选边排序。不等于九道独立排序模板题，也不因任意序列可先排序就增加次数。
字符串处理与匹配 主解8 替代0 合计8 沿用主表 H 类，含替换、映射、扫描、结构解析与消除状态；不是八题都需要 KMP、AC 自动机等高级字符串算法。
搜索与显式枚举 主解9 替代0 合计9 沿用主表 S 类：回溯、BFS 状态搜索、显式枚举及断环枚举等。一题可与 BFS/DFS 重叠；不把所有 DP 转移循环都贴成枚举。
强连通分量 SCC 主解0 替代1 合计1 《信息传递》可求 SCC，也可直接 DFS 找环；不能把它读成必需掌握 Tarjan。
LCA 主解0 替代0 合计0 这些指定题位中未识别出 LCA 独立考点。
Dijkstra 主解0 替代0 合计0 不把“所有最短路”都算成 Dijkstra；《换教室》的代表方案为 Floyd。
严格次短路 主解0 替代0 合计0 与普通最短路分开统计。
Floyd 主解1 替代0 合计1 全源最短距离预处理。
鸽巢原理 主解0 替代0 合计0 未识别出作为独立专题的典型应用；频次界可有鸽巢式解释，不据此给所有频次题贴该标签。
EXGCD 主解1 替代0 合计1 扩展欧几里得求线性同余解。
容斥原理 主解1 替代0 合计1 由补集和超半数限制组织计数 DP。
逆元 主解1 替代1 合计2 《计算系数》可用阶乘逆元，也可用杨辉三角递推，不需要逆元。
孙子定理 / CRT 主解0 替代0 合计0 《小凯的疑惑》的本地 CRT 标签不直接计数；代表思路是互质数不可表示最大值的数学证明。
树状数组 主解1 替代0 合计1 《火柴排队》统计逆序对；也可归并排序。
线段树 主解1 替代0 合计1 《策略游戏》固定选择线段树路线作为代表；ST 表是另一条路线。
树形 DP 主解1 替代1 合计2 含树上计数递推；树形背包属于树形 DP 的子类。
树形背包 主解0 替代1 合计1 《金明的预算方案》主统计选主件附件组合的分组背包；树形依赖背包作为替代路线。
树的直径 主解0 替代0 合计0 《树网的核》在四题卷 T4，不在本样本中。
状压 DP 主解0 替代0 合计0 《乌龟棋》是各类卡片数量构成的多维 DP；普通子集枚举也不自动计为状压 DP。
堆排序（严格含义） 主解0 替代0 合计0 没有将使用堆 / 优先队列等同于 heapsort。使用普通排序的题也不因可换堆排序就计入。
堆 / 优先队列（补充拆分） 主解2 替代1 合计3 《合并果子》《廊桥分配》有明确堆应用；《社团招新》另有小根堆路线，主统计选排序。
BFS 主解2 替代1 合计3 《奶酪》可用 BFS 或 DFS 判断连通性，主统计选并查集。
DFS 主解3 替代4 合计7 包含图/树遍历及回溯搜索；不把任意递归或普通子集循环都计成 DFS。
前缀和 / 前缀累计 主解4 替代2 合计6 含一维、二维以及按类别前缀累计。《均分纸牌》的前缀盈亏可以原地维护，不要求显式前缀数组。 本轮补录《括号序列》的前缀和优化路线；并非所有区间 DP 实现都必须采用该优化。
差分 主解2 替代0 合计2 统计相邻高度的正增量。
二分 主解3 替代1 合计4 《儒略日》可对日期二分，主统计选历法分段模拟。
普通队列 主解4 替代2 合计6 计入 BFS、Kahn 拓扑的显式队列工具；优先队列归堆，不混入 FIFO 队列。
显式栈 主解3 替代0 合计3 不把所有递归函数的系统调用栈计入；《消消乐》也可走数组 DP 路线。
模拟 / 规则实现 主解17 替代0 合计17 沿用前述主表的代表性类别；不把每道算法最终都需写代码理解为模拟。
二叉树（独立专题） 主解0 替代0 合计0 不把堆、线段树的内部结构自动重复统计为二叉树专题，也不把任意二叉递归展开当作考点。
数学（宽口径） 主解21 替代0 合计21 包括基础算术、数论、组合计数、高精度、运动关系等；不能与 EXGCD 等窄专题直接比较难度。
图论（含显式树结构） 主解9 替代1 合计10 原图算法类 F 为 6 题，树上算法类 T 为 3 题，两类此样本无重叠；另列《金明》的显式树形依赖解法。
